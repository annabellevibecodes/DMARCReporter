OAuth settings (Gmail OAuth & Office 365)

Gmail: create an OAuth client (type “Web application”) in Google Cloud Console with redirect URI {{"{"}}BASE_URL{{"}"}}/oauth/google/callback, then enter its client ID and secret here; you will be sent through Google's consent screen after saving.
Office 365 (IMAP): Microsoft has disabled password auth for IMAP. Register an Entra ID app with the IMAP.AccessAsApp application permission (admin consent required), grant the service principal access to the mailbox via New-ServicePrincipal + Add-MailboxPermission, then enter tenant ID, client ID, and client secret.
Office 365 (Microsoft Graph API): register an Entra ID app with the Mail.ReadWrite application permission (admin consent required) instead of IMAP.AccessAsApp, then enter tenant ID, client ID, and client secret. No IMAP access is used or required.
